یادآرا یک ربات متن‌باز دوزبانهٔ تلگرام برای ثبت یادآوری است. جمله‌ات را به فارسی بنویس یا با دکمه‌ها زمان و موضوع را وارد کن؛ ربات بعد از تأیید، آن را ذخیره می‌کند و در زمان مقرر به تو پیام می‌دهد. برای پردازش متن به API پولی هوش مصنوعی وابسته نیست.

> **وضعیت:** نسخهٔ اولیهٔ قابل اجرا. تست‌های خودکار و گفت‌وگوی شبیه‌سازی‌شده اجرا شده‌اند، اما ارتباط با یک ربات واقعی تلگرام هنوز تأیید نشده است. برای دارو یا موارد حیاتی، فقط به این ابزار متکی نباشید.

## نمونهٔ استفاده

نمونهٔ زیر یک گفت‌وگوی **نمایشی** است:

```text
شما:    فردا ساعت ۳ عصر قرص بخورم
یادآرا: یادآوری چند بار تکرار شود؟
شما:    یک‌بار
یادآرا: موضوع: قرص بخورم
        زمان: ۱۴۰۵/۰۸/۱۵، ۱۵:۰۰ (Asia/Tehran)
        تکرار: یک‌بار
        تأیید می‌کنی؟
شما:    ✅ تأیید
یادآرا: ثبت شد ✅ شناسه: ۱
```

تاریخ نمایش‌داده‌شده به روز ثبت و منطقهٔ زمانی بستگی دارد.

- 📅 تاریخ شمسی عددی، امروز، فردا و پس‌فردا

- 🔒 پاسخ فقط در چت خصوصی و محدودکردن دسترسی به داده‌های هر کاربر

## شروع سریع

### پیش‌نیازها

- Python 3.10 یا جدیدتر و دسترسی به سرورهای تلگرام
- توکن رباتی که از [BotFather](https://t.me/BotFather) ساخته‌اید

### نصب و اجرا

```bash
git clone <آدرس-مخزن-خودتان>
cd yadara-telegram-reminder
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # Windows: copy .env.example .env
```

در فایل `.env` مقدار `BOT_TOKEN` را وارد کنید، سپس:

```bash
python -m yadara
```

در تلگرام ربات خودتان را باز کنید و `/start` بفرستید. در ویندوز، اگر دادهٔ مناطق زمانی موجود نبود، `pip install tzdata` را اجرا کنید. توکن را در مخزن عمومی قرار ندهید.

### اجرا با Docker

پس از ساخت و تنظیم `.env`:

```bash
docker compose up -d --build
docker compose logs -f
```

داده‌ها در volume نگهداری می‌شوند. فقط **یک نمونه** از ربات را با هر دیتابیس اجرا کنید.

## دستورات

| دستور | کاربرد |
| --- | --- |
| `/start` | شروع و نمایش منو |
| `/language fa` یا `/language en` | تغییر زبان ربات |
| `/help` | راهنمای ربات |
| `/list` یا `/list 2` | فهرست یادآوری‌های فعال |
| `/edit 123` | ویرایش موضوع و زمان |
| `/delete 123` | حذف یادآوری |
| `/timezone Europe/London` | تنظیم منطقهٔ زمانی |
| `/failed` | نمایش ۵۰ ارسال ناموفق اخیر |
| `/retry 123` | تلاش دوباره برای ارسال ناموفق |
| `/cancel` | لغو فرایند جاری |

زبان پیش‌فرض فارسی است؛ برای انگلیسی `/language en` را بفرستید. منطقهٔ زمانی با زبان تغییر نمی‌کند. پیش‌فرض منطقهٔ زمانی `Asia/Tehran` است. تغییر آن زمان واقعی یادآوری‌های قبلی را تغییر نمی‌دهد. زمان‌های موجود در فهرست در منطقهٔ زمانی فعلی کاربر نمایش داده می‌شوند.

## تنظیمات

| متغیر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `BOT_TOKEN` | — | توکن دریافتی از BotFather؛ اجباری |
| `DATABASE_PATH` | `data/yadara.db` | مسیر فایل SQLite |
| `DEFAULT_TIMEZONE` | `Asia/Tehran` | منطقهٔ زمانی پیش‌فرض IANA |
| `POLL_INTERVAL_SECONDS` | `15` | فاصلهٔ بررسی یادآوری‌ها، بر حسب ثانیه |

در Docker، مسیر دیتابیس را در `/app/data` نگه دارید تا روی volume ذخیره شود. `.env.example` نمونهٔ تنظیمات است.

## تست

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

تست‌ها شامل پردازش تاریخ و ساعت، مالکیت، دیتابیس، مهاجرت، ارسال معوق و یک گفت‌وگوی شبیه‌سازی‌شده هستند؛ ارتباط واقعی با تلگرام را آزمایش نمی‌کنند.

## محدودیت‌ها و نگهداری

- پردازش زبان مبتنی بر قواعد است، نه هوش مصنوعی. در حالت انگلیسی today، tomorrow و تاریخ میلادی ISO پشتیبانی می‌شوند؛ در حالت فارسی تاریخ شمسی استفاده می‌شود. تاریخ شمسی عددی و روزهای نسبی بالا پشتیبانی می‌شوند؛ نام ماه، روز هفته، تاریخ میلادی ورودی و عبارت‌هایی مثل «دو ساعت دیگر» فعلاً پشتیبانی نمی‌شوند. ساعت ۱ تا ۱۲ باید با صبح، عصر یا شب مشخص شود.
- سرور باید روشن و به تلگرام متصل باشد. یک یادآوری معوق بعد از اتصال مجدد ارسال می‌شود؛ برای یادآوری تکراری، نوبت‌های ازدست‌رفته به یک پیام خلاصه و نوبت بعدی در آینده تنظیم می‌شود. خطاهای موقت تا ۱۰ بار با فاصلهٔ افزایشی تکرار می‌شوند.
- تضمین ارسال دقیقاً یک‌بار یا دیده‌شدن پیام وجود ندارد؛ ممکن است در قطعی بین ارسال و ثبت وضعیت، پیام تکراری شود. حذف هم‌زمان ممکن است جلوی ارسال در حال انجام را نگیرد.
- در گذار ساعت تابستانی، زمان اولیهٔ ناموجود یا مبهم رد می‌شود. برای تکرار، زمان ناموجود به زمان معتبر بعدی منتقل می‌شود و در ساعت تکراری اولین وقوع انتخاب می‌شود؛ ساعت اصلی برای نوبت‌های بعدی حفظ می‌شود.
- گفت‌وگوی ناتمام بعد از ری‌استارت پاک می‌شود، اما یادآوری تأییدشده در دیتابیس باقی می‌ماند. پیام و اطلاعات کاربر در دیتابیس ذخیره می‌شوند؛ دسترسی به آن و پشتیبان‌ها را محدود کنید.

برای پشتیبان‌گیری امن از SQLite در حالت WAL از backup API استفاده کنید، نه کپی فایل اصلی هنگام اجرا:

```bash
python -c "import sqlite3; a=sqlite3.connect('data/yadara.db'); b=sqlite3.connect('backup.db'); a.backup(b); b.close(); a.close()"
```

پیش از اتکا، بازیابی پشتیبان را آزمایش کنید. اجرای دائمی ممکن است هزینهٔ میزبانی داشته باشد.
